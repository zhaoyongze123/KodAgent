# Product

## Register

product

## Users

可道云中的 OA 用户，在日常办公场景中通过 KodAgent 查询待办、日程、会议室和党务文件，并执行受审批约束的业务操作。

## Product Purpose

KodAgent 将自然语言请求连接到 OA 业务工具。它需要让用户看见清晰、可恢复的执行过程，并在模型、权限、业务系统或网络异常时说明原因和下一步操作。

## Brand Personality

清晰、可靠、克制。界面应优先帮助用户理解当前发生了什么，而不是暴露框架、堆叠内部错误或展示无法行动的技术细节。

## Anti-references

避免直接展示 Next.js 开发覆盖层、原始异常堆栈、无解释的英文错误、重复状态卡片和无法操作的错误提示。

## Design Principles

- 错误在发生位置附近解释，并提供明确的下一步。
- Agent 的过程可读，底层工具和框架细节按需展开。
- 模型保持灵活，业务权限、能力和输入校验由代码负责。
- 同一类交互使用统一的组件、文案和状态模型。

## Accessibility & Inclusion

遵循现有组件库的键盘可操作性和焦点规范；图标按钮必须有可访问名称；错误不能只依赖颜色表达；支持减少动态效果。
