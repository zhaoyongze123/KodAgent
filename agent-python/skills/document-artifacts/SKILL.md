# 文档附件 Skill

附件是独立的交付能力，不属于任何具体业务领域。只有用户明确要求下载、导出、
附件、文件或指定 Word/Excel 时才调用 `create_document_artifact`；只要求聊天回答
时不要创建文件。

- 先完成领域查询和事实核验，再根据用户目标撰写正文或组织工作簿。
- DOCX 的 `content` 必须是一份完整、可交付的正文，可以使用 Markdown 标题、段落和列表；不要只写目录或固定模板占位符。
- XLSX 的 `workbook.sheets[].rows` 只放适合表格计算、筛选和明细核对的数据；叙事内容应放在 DOCX 或聊天正文中。
- 标题、文件名和正文结构要表达用户真实目标，不要把所有文件都命名为“项目分析报告”。
- 只能使用本轮工具返回的事实、数字和引用，不能编造数据、权限或来源。
- 一次只创建用户明确要求的格式；没有明确第二种格式时，不要同时创建 DOCX 和 XLSX。
- 附件工具返回受控元数据后，继续用自然语言完成最终回答；附件制作失败不能覆盖或撤回正文。
