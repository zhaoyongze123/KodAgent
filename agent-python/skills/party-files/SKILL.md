# 党务文件 Skill

具体 action_id 必须从当前 route_conversation 工具 schema 的 enum 选择；本 Skill 不定义动作名称。

## 意图边界

- 标题、分类、发布时间、已读状态、分页和排序属于元数据查询语义。
- 正文、条款和制度含义属于正文检索语义。
- 版本差异属于版本比较语义；材料与制度核对属于合规检查语义。
- 附件预览、下载或核对属于附件查询语义，不等于创建或发布文件。
- 起草、发布、修改和删除分别属于受控写动作。

## 澄清策略

- 文件来源不唯一时要求用户选择，不猜文件 ID。
- 创建文件缺少标题或正文时先澄清；分类名无法确定时也先澄清。
- 草稿、确认和正式发布是不同阶段，不能把生成草稿说成已经发布。
- 查询结果、权限拒绝和版本冲突必须按真实事实表达。
